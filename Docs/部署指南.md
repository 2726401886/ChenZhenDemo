# ChenZhenDemo WebGL 部署指南

## 快速开始

### 方案A：本地打包（推荐）

1. 用 Unity Hub 打开项目 `D:\ChenZhenDemo`
2. 菜单栏点击 `Build → Build WebGL (GitHub Pages)`
3. 等待打包完成，产物输出到 `docs/` 目录
4. 本地测试：用 Live Server 打开 `docs/index.html`
5. 提交推送到 GitHub

### 方案B：GitHub Actions 自动打包

1. 推送代码到 `main` 分支
2. GitHub Actions 自动执行 WebGL 打包
3. 打包产物自动部署到 `gh-pages` 分支
4. 开启 GitHub Pages（Source: gh-pages）

---

## GitHub Pages 开启步骤

1. 进入仓库 → Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `gh-pages` / `/(root)`
4. 保存，等待几分钟生效
5. 访问：`https://2726401886.github.io/ChenZhenDemo/`

## CI 密钥配置

在仓库 Settings → Secrets and variables → Actions 中添加：

| 名称 | 说明 |
|------|------|
| `UNITY_LICENSE` | Unity 许可证文件内容（.ulf） |
| `UNITY_EMAIL` | Unity 账号邮箱 |
| `UNITY_PASSWORD` | Unity 账号密码 |

### 获取 Unity License

1. 打开 Unity Hub → Preferences → Licenses
2. 点击 Advanced → Manual Activation
3. 生成 `.ulf` 文件
4. 复制文件内容粘贴到 `UNITY_LICENSE` Secret

## 常见问题

### 1. 页面空白
- 打开 F12 控制台查看报错
- 确认 `.nojekyll` 文件存在

### 2. WASM 加载失败
- GitHub Pages 默认不支持 `.wasm` MIME 类型
- 解决：在仓库根目录创建 `static/.htaccess`（Apache）或联系 GitHub 支持

### 3. 存档丢失
- WebGL 的 PlayerPrefs 存储在浏览器 IndexedDB 中
- 清除浏览器数据会丢失存档
- 提示用户不要清除站点数据

### 4. 内存不足
- Unity Player Settings → Memory Size 设为 256 或 512
- 项目已配置 `memorySize = 256`
