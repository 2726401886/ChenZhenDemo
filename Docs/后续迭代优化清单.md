# 后续迭代优化清单

## 概述
本文档列出项目后续可迭代优化的功能点，作为下一阶段开发任务参考。
不改动现有稳定代码，仅作为迭代备选功能。

---

## 战斗层优化

### 1. 受击硬直系统
- **优先级**：高
- **预计工时**：4-6小时
- **描述**：角色/敌人受击后产生短暂硬直，无法进行攻击/移动
- **实现要点**：
  - 在CombatSystem中添加硬直时间参数
  - 受击时设置硬直状态标志
  - 硬直期间禁用输入/移动
  - 支持硬直中断（可配置是否可被打断）

### 2. 无敌帧系统
- **优先级**：高
- **预计工时**：3-4小时
- **描述**：角色受击后获得短暂无敌时间
- **实现要点**：
  - 在CombatSystem中添加无敌帧时间参数
  - 受击后设置无敌状态标志
  - 无敌期间忽略伤害判定
  - 支持无敌帧视觉效果（闪烁/透明度变化）

### 3. 武器系统
- **优先级**：中
- **预计工时**：8-12小时
- **描述**：支持多种武器类型，各有不同属性
- **实现要点**：
  - 创建Weapon基类和具体武器子类
  - 武器属性：伤害、攻击速度、攻击范围、耐久度
  - 武器切换系统
  - 武器特效和音效
  - 武器耐久度消耗

### 4. 多类型敌人
- **优先级**：中
- **预计工时**：6-8小时
- **描述**：添加不同类型的敌人，各有独特行为
- **实现要点**：
  - 创建敌人基类和具体敌人子类
  - 近战敌人、远程敌人、坦克敌人
  - 不同敌人有不同的攻击方式和属性
  - 敌人预制体配置

### 5. Combo连击系统
- **优先级**：低
- **预计工时**：6-8小时
- **描述**：支持连续攻击产生连击效果
- **实现要点**：
  - 连击计数器
  - 连击窗口时间
  - 连击伤害加成
  - 连击动画切换

## AI层优化

### 1. 巡逻点系统
- **优先级**：高
- **预计工时**：4-5小时
- **描述**：敌人在指定巡逻点之间移动
- **实现要点**：
  - 创建PatrolPoint组件
  - 敌人AI添加巡逻状态
  - 巡逻点路径配置
  - 巡逻速度和等待时间

### 2. NavMesh寻路支持
- **优先级**：高
- **预计工时**：6-8小时
- **描述**：使用Unity NavMesh系统进行智能寻路
- **实现要点**：
  - 烘焙NavMesh地形
  - 敌人AI使用NavMeshAgent
  - 避障和路径平滑
  - 动态障碍物处理

### 3. 仇恨衰减系统
- **优先级**：中
- **预计工时**：3-4小时
- **描述**：敌人对玩家的仇恨值随时间衰减
- **实现要点**：
  - 仇恨值变量
  - 仇恨衰减曲线
  - 仇恨阈值（脱离战斗）
  - 多目标仇恨管理

### 4. 群体AI行为
- **优先级**：低
- **预计工时**：8-12小时
- **描述**：敌人之间协同作战
- **实现要点**：

  - 包围战术

  - 集群攻击

## 注意事项

1. **不改动现有代码**：所有迭代功能应在新脚本中实现，不修改现有稳定代码
2. **保持兼容性**：新功能应与现有EventBus架构兼容
3. **模块化设计**：每个功能应独立模块，便于单独启用/禁用
4. **性能优先**：实现时注意性能影响，特别是移动端和WebGL平台
5. **文档更新**：实现新功能后更新ReadMe.md和相关文档
